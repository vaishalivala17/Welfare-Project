# Welfare Project – Responsive UI

## Project Description
This is a **welfare project UI** created using **HTML and CSS** with **media queries** for responsiveness.  
The project focuses only on **frontend design**, providing a clean and user-friendly interface for a welfare-related website.

No backend or database is used in this project. The main goal is to practice **responsive web design** and layout structuring.

---

## Objectives
- To design a responsive welfare website UI
- To understand CSS media queries
- To improve layout and styling skills using pure CSS
- To build a mobile-friendly interface

---

## Features
- Responsive layout using CSS media queries
- Clean and simple UI design
- Mobile, tablet, and desktop friendly
- Structured sections for welfare information
- User-friendly design

---

## Technologies Used
- HTML5  
- CSS3  
- CSS Media Queries
